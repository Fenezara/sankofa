# Plantes médicinales de Côte d'Ivoire — Info éducative

## Avertissement fondamental
Ce document fournit des informations éducatives sur les plantes médicinales traditionnelles ivoiriennes. **Aucune prescription**. Les plantes peuvent interagir avec des médicaments et ne doivent pas remplacer un traitement médical. Toujours consulter un·e médecin.

## Contexte
En Côte d'Ivoire, la médecine traditionnelle est largement utilisée (estimation : 60%+ de la population y a recours). Certaines plantes ont des bénéfices validés scientifiquement, d'autres manquent d'études. Sankofa informe, ne prescrit pas.

## Plantes médicinales validées

### 1. Neem (Margousier) — *Azadirachta indica*
**Noms locaux** : neem, nimba, gôni

**Usages traditionnels** :
- Paludisme (fièvre)
- Soins de peau (acné, eczéma)
- Antiseptique

**Bénéfices validés** :
- Propriétés antipaludiques reconnues (complément, pas substitut)
- Antibactérien léger
- Anti-inflammatoire

**Précautions** :
- Ne remplace pas le traitement antipaludique (ACT)
- Interactions possibles avec médicaments
- Éviter pendant grossesse
- Éviter ingestion prolongée

### 2. Moringa — *Moringa oleifera*
**Noms locaux** : moringa, arzân, neverdie

**Usages traditionnels** :
- Malnutrition
- Fatigue
- Allaitement (boost lait)

**Bénéfices validés** :
- Très riche en nutriments (fer, vitamines A/C, protéines)
- Antioxydant
- Études OMS pour malnutrition infantile

**Précautions** :
- Qualité variable (non réglementé en CI)
- Pas de surdosage
- Éviter racines pendant grossesse

### 3. Kinkeliba — *Combretum micranthum*
**Noms locaux** : kinkeliba, kinkelé, sehédonga

**Usages traditionnels** :
- Digestion
- Fièvre
- Fatigue
- Laxatif léger

**Bénéfices validés** :
- Digestif reconnu
- Cholagogue (stimule la bile)
- Stimulant léger

**Précautions** :
- Peut interagir avec médicaments
- Éviter pendant grossesse
- Laxatif → ne pas abuser

### 4. Gingembre — *Zingiber officinale*
**Noms locaux** : gingembre, djindja, afu

**Usages traditionnels** :
- Nausées
- Rhume
- Mal de gorge
- Aphrodisiaque

**Bénéfices validés** :
- Anti-nauséeux validé OMS
- Anti-inflammatoire léger
- Antibactérien

**Précautions** :
- Brûlures d'estomac si excès
- Interactions anticoagulants
- Éviter en cas d'ulcère

### 5. Baobab (fruit) — *Adansonia digitata*
**Noms locaux** : baobab, bouye, lobo

**Usages traditionnels** :
- Fatigue
- Malnutrition
- Fièvre
- Diarrhée

**Bénéfices validés** :
- Très riche en vitamine C (plus que orange)
- Antioxydant
- Anti-diarrhéique léger

**Précautions** :
- Qualité variable
- Éviter en cas de constipation

## Message-clé de Sankofa

Les plantes médicinales peuvent aider en complément, mais :
1. **Ne jamais arrêter un traitement médical** pour une plante
2. **En cas de fièvre** → consulter (test paludisme), ne pas se contenter de neem
3. **Vérifier la qualité** (non réglementé en CI)
4. **Éviter pendant grossesse** sauf avis médical
5. **Toujours informer le médecin** des plantes utilisées
