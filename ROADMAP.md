## 🚀 V5.0.0 — Q1 2027 — "Voice & Connection"

### Objectif : Rendre Sankofa pleinement accessible à l'oral

### Features
1. **🎙️ Audio multilingue natif**
   - ASR (speech-to-text) : FR + Nouchi + Dioula + Baoulé
   - TTS (text-to-speech) : voix ivoiriennes francophones
   - Intégration Azure Speech / Google TTS / ElevenLabs
   - Bouton micro permanent + mode "conversation vocale"

2. **🤝 Mode pair-aidant réel**
   - Chat anonyme entre jeunes vivant la même situation
   - Modération IA + humaine (sécurité)
   - Matchmaking par domaine (SSR, addicto, psy, etc.)
   - "Tu n'es pas seul·e" renforcé

3. **📊 Analytics dashboard public**
   - Santé des jeunes CI agrégée (anonyme)
   - Tendances par région, âge, genre, domaine
   - Outil de plaidoyer pour décideurs

4. **🔔 Rappels push intelligents**
   - TPE J+7 (test VIH)
   - Pilule quotidienne (heure personnalisée)
   - Dépistage IST annuel
   - Vaccination HPV (filles 9-14 ans)
   - Suivi post-consultation

5. **🌍 Carte TPE interactive**
   - Géolocalisation temps réel
   - Horaires d'ouverture + affluence
   - Bouton "réserver créneau"
   - Directions (Google Maps intégration)

### Impact attendu
- +50% engagement (audio + pair-aidant)
- +30% rétention (rappels)
- Accessibilité analphabètes + malvoyants

## 🩺 V6.0.0 — Q2 2027 — "Teleconsultation réelle"

### Objectif : Bridge vers un vrai médecin ivoirien

### Features
1. **🩺 Visio médecin intégrée**
   - Jitsi Meet embed dans l'app
   - Réseau médecins partenaires AIBEF
   - Paiement Mobile Money (3000 F / téléconsultation)
   - Dossier partagé (opt-in patient)

2. **💊 Ordonnance numérique** (légal CI)
   - Si médecin partenaire certifié
   - Signature numérique + QR code
   - Pharmacies partenaires
   - Historique chiffré

3. **📋 Dossier médical partagé**
   - Carnet chiffré + médecin (opt-in patient)
   - Synthèse consultation automatique
   - Résumé LLM (validé par médecin)
   - Portabilité cross-device

4. **💳 Assurance santé micro-paiement**
   - 100 F/jour = téléconsultations illimitées
   - Partenariat assurance CI
   - Wave / Orange Money / MTN

5. **🏥 Réseau centres certifiés**
   - API partenaires (CHU, cliniques, AIBEF)
   - Disponibilité temps réel
   - Réservation en ligne
   - Feedback post-consultation

### Impact attendu
- Revenus : 3000 F × N téléconsultations/mois
- Accessibilité soins : +60% jeunes zone rurale
- Données santé : agrégées (privacy-safe) pour recherche

## 🧠 V7.0.0 — Q3 2027 — "AI Sentinelle Avancée"

### Objectif : Prévention proactive par IA

### Features
1. **🧠 IA prédictive**
   - Détection précoce dépression/anxiété (ML local)
   - Modèle entraîné sur données anonymisées CI
   - Alertes précoces avant crise
   - Recommandations personnalisées

2. **📈 Journal d'humeur chiffré**
   - Track humeur quotidienne (emoji + notes)
   - Graphiques 7/30/90 jours
   - Corrélations (sommeil, alimentation, cycle)
   - Partage avec médecin (opt-in)

3. **🎯 Exercices d'auto-apaisement guidés**
   - Respiration 4-7-8 animée
   - Ancrage 5-4-3-2-1 interactif
   - Méditation guidée audio (FR + Nouchi)
   - Cohérence cardiaque

4. **🔄 Reformulation cognitive douce**
   - Pensées négatives détectées
   - Alternatives proposées (pas de TCC formelle)
   - Journal de pensées chiffré
   - Partage avec psy (opt-in)

5. **📚 Bibliothèque ressources psy**
   - Articles validés OMS/AIBEF
   - Vidéos éducatives CI
   - Podcasts santé mentale
   - Témoignages de guérison

### Impact attendu
- Santé mentale : -30% crises (détection précoce)
- Autonomie : +40% gestion émotionnelle
- Réduction honte psy (normalisation)
