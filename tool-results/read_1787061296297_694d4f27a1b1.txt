     9→## 🎯 Vision du projet
    10→
    11→**Doc Confida** est un assistant IA de santé sexuelle et reproductive (SSR)
    12→pour les jeunes de **15-19 ans en Côte d'Ivoire**, accessible via une
    13→interface de type WhatsApp (web demo d'abord, vraie intégration WhatsApp plus tard).
    14→
    15→**Promesse produit** : « Ton grand frère santé, 100% anonyme, 24/7, en Nouchi. »
    16→
    17→**Niche différenciante** (vs concurrents directs) :
    18→- Spécialisation **urgence temporelle TPE 72h** (aucun concurrent ne le fait)
    19→- Cible **15-19 ans** (La Ruche Health cible adultes, Aimee cible 16-24 SA)
    20→- **Ton Nouchi maîtrisé** + audit jeunes rémunérés (inspiré d'Aimee)
    21→- **Partenariat AIBEF** (à signer, c'est le moat institutionnel)
    22→- **Pricing hybride** : gratuit (triage) + 1500 FCFA (plan d'action) + 3000 FCFA (téléconsultation humaine)

    28→### Concurrents directs critiques en Côte d'Ivoire
    29→1. **La Ruche Health** 🇨🇮 — IA + médecins WhatsApp/App, 300k+ questions répondues, SSR déjà couvert.
    30→   Leader local installé. Faiblesse : pas de focus 15-19 ans, pas de TPE 72h, ton institutionnel.
    31→2. **Waspito** 🇨🇲🇨🇮 — 5,2 M$ levés, 850+ médecins, IA AHIM déployée, prix 3 000-6 000 FCFA.
    32→   Faiblesse : généraliste, pas d'anonymat radical, pas de focus jeunesse.
    33→3. **Zencey** 🇨🇮 — téléconsult classique depuis 2019, pas d'IA conversationnelle.
    34→4. **Doc Chap** 🇨🇮 — téléconsult, référence explicite au Décret 2018-361 (à copier).
    35→
    36→### Modèles conceptuels à copier (hors CI)
    37→- **Aimee / Self-Cav** 🇿🇦 (Audere Africa) — compagnon IA WhatsApp VIH/PrEP ados 16-24,
    38→  hybride IA + infirmière, intégration Ministère Santé SA. **Modèle de référence absolu.**
    39→- **Roo** 🇺🇸 (Planned Parenthood) — chatbot SSR ados 13-17, gratuit anonyme.
    40→- **K Health** 🇮🇱🇺🇸 — 439 M$ levés, seul modèle B2C rentable : IA gratuite + médecin 35 $.
    41→- **Ada Health** 🇩🇪 — 13 M users, CE Class IIa, raisonnement bayésien.
    42→- **Sister Unathi** 🇿🇦 (Wits) — omnicanal, conforme POPIA (modèle de conformité).
    43→- **Nurse Nisa** 🇨🇩 (Ipas+Dimagi) — 7 000 users en 3 ans, francophone mais croissance lente.
    44→- **Daktari360** 🇰🇪 — gratuit, financé Google+Facebook+GIZ, bilingue EN+SW.
    45→
    46→### Cas d'échec à ne pas reproduire
    47→- **Babylon Health** 🇬🇧 (4 B$ valuation → faillite 2023) :
    48→  surpromesse IA + modèle économique cassé + expansion trop rapide.
    49→  VRAIE cause de mort : pas les erreurs de diagnostic (faux), mais unit economics NHS + scandale MHRA.
    50→- **Woebot** 🇺🇸 — fermé mi-2025 après 8 ans, raison officielle : « incertitude réglementaire ».
    51→
    52→### Leçons transversales
    53→1. Aucun acteur mondial n'a réussi en B2C pur avec micro-paiement par conseil IA sans médecin attaché.
    54→   → Le seul modèle B2C viable est « IA gratuite + humain payant » (K Health).
    55→2. Tous les succès ont un partenaire institutionnel (Ada-NHS, K-Mayo, Roo-Planned Parenthood, Aimee-Ministère SA).
    56→3. La certification dispositif médical est le vrai moat (Ada = seul CE Class IIa).
    57→4. Le sujet « hôpital IA toutes spécialités autonome » est de la science-fiction réglementaire en 2026,
    58→   même en Chine (Tsinghua = simulation, pas patients réels).

    62→## ⚖️ Cadre réglementaire CI (à respecter)
    63→
    64→- **Décret n° 2018-361 du 29 mars 2018** portant réglementation de la télémédecine en Côte d'Ivoire.
    65→- **CNOMCI** (Conseil National de l'Ordre des Médecins de CI) — strict sur l'exercice illégal de la médecine.
    66→- **ARTCI** (Autorité de Régulation des Télécommunications/TIC) — protecteur des données personnelles
    67→  (loi 2013, révisée). A déjà sanctionné en 2024 l'usage non autorisé de données biométriques.
    68→  Données de santé = données sensibles.
    69→- **AIBEF** (Association Ivoirienne pour le Bien-Être Familial) — pionnière planning familial depuis 1979,
    70→  affiliée IPPF. Partenaire institutionnel cible.
    71→- **Loi sur l'avortement CI** : très stricte (autorisé uniquement si vie de la mère en danger).
    72→  → Ne JAMAIS donner de conseils d'avortement. Rediriger vers Planning Familial / ONG.

    76→## 🛡️ Guardrails médicaux absolus (à coder en dur dans le backend)
    77→
    78→L'IA ne doit JAMAIS :
    79→1. Poser un diagnostic formel
    80→2. Prescrire un médicament sur ordonnance ou donner un dosage personnalisé
    81→3. Donner des conseils d'avortement (loi CI)
    82→4. Donner des méthodes de suicide ou d'automutilation
    83→5. Juger ou culpabiliser
    84→
    85→**Red flags** (mots-clés qui déclenchent une réponse pré-écrite sécurisée, sans LLM libre) :
    86→- Avortement / IVG / interrompre grossesse
    87→- Suicide / me tuer / en finir / vouloir mourir
    88→- Viol / agression sexuelle / abus
    89→- Urgence vitale / saignement abondant / perte de conscience
    90→
    91→Pour chaque red flag : réponse empathique + orientation immédiate vers structure physique
    92→(n° vert Ministère Santé, urgences CHU Cocody/Treichville, ONG spécialisée).

   154→### Backend API routes
   155→
   156→#### `POST /api/chat`
   157→Body : `{ message: string, history: Message[] }`
   158→Response : `{ reply: string, triageLevel: 'info'|'orientation'|'urgence', tpeActivated?: boolean }`
   159→
   160→Pipeline :
   161→1. Vérification red flags (regex/keyword match) → si match, retourner réponse pré-écrite sécurisée
   162→2. RAG retrieval : chercher dans la base de protocoles (fichiers texte) les passages pertinents
   163→3. Construction du prompt système (ton grand frère, Nouchi léger, garde-fous)
   164→4. Appel LLM via z-ai-web-dev-sdk avec température basse (0.3)
   165→5. Post-check de la réponse : si elle contient des mots interdits (dosages, diagnostics formels),
   166→   la bloquer et renvoyer une réponse de repli
   167→6. Persistance en base (Conversation + Message)
   168→
   169→#### `POST /api/triage`
   170→Body : `{ message: string }`
   171→Response : `{ level: 'info'|'orientation'|'urgence', reasons: string[], tpeActivated: boolean }`
   172→Logique simplifiée de triage basée sur mots-clés + détection temporelle (ex: "hier soir" → < 24h → TPE).
   173→
   174→#### `POST /api/payment/initiate`
   175→Body : `{ tier: 'plan_action' | 'teleconsultation', phone: string }`
   176→Response simulée : `{ status: 'pending', transactionId: string, message: string }`
   177→(Pas de vraie intégration CinetPay — juste la simulation du flux.)

   192→### Schéma Prisma
   193→
   194→```prisma
   195→model Conversation {
   196→  id        String   @id @default(cuid())
   197→  anonymousId String @unique // UUID, pas de nom réel
   198→  createdAt DateTime @default(now())
   199→  updatedAt DateTime @updatedAt
   200→  messages  Message[]
   201→}
   202→
   203→model Message {
   204→  id        String   @id @default(cuid())
   205→  conversationId String
   206→  conversation Conversation @relation(fields: [conversationId], references: [id])
   207→  role      String   // 'user' | 'assistant'
   208→  content   String
   209→  triageLevel String?
   210→  createdAt DateTime @default(now())
   211→}
   212→
   213→model PaymentTransaction {
   214→  id        String   @id @default(cuid())
   215→  anonymousId String
   216→  tier      String   // 'plan_action' | 'teleconsultation'
   217→  amount    Int      // en FCFA
   218→  phone     String   // haché idéalement
   219→  status    String   // 'pending' | 'success' | 'failed'
   220→  createdAt DateTime @default(now())
   221→}
   222→```

   254→- VIOL / agression sexuelle : soutien total, "ce n'est pas ta faute",

   261→{PROTOCOLS_RETRIEVED}
   262→
   263→WORKFLOW :
   264→1. Accuse réception avec empathie + rassure sur anonymat.
   265→2. Pose 1-2 questions de triage MAX si info manquante.

   267→4. Termine par orientation locale (CHU Cocody, AIBEF Abidjan, etc.).

   404→### Décision 2 — Stack animations : **Framer Motion + CSS 3D + SVG** (PAS React Three Fiber)
   405→
   406→Justification : marché cible = smartphones Tecno/Infinix/Itel (60%+ en CI), 2-4 Go RAM,
   407→MediaTek Helio A22/G35, Android 8-11 Go Edition, data 3G/4G chère. R3F = bundle +150-200 KB,
   408→lagguerait sur ces devices. Choix responsable : Framer Motion (~30 KB) + CSS 3D transforms
   409→(perspective, rotateY, rotateX) + SVG animés + canvas léger pour particules.
   410→
   411→**Détection device capability** : `navigator.hardwareConcurrency` et `navigator.deviceMemory`
   412→pour dégrader gracieusement (désactiver particules, parallaxe sur devices faibles).
